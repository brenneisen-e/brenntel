Wie funktioniert das?

            
Dieses Tool nutzt die WordPress REST API, die seit WordPress 4.7 (2016) in jeder Installation enthalten ist. Öffentliche Inhalte wie Beiträge, Seiten und Medien sind ohne Authentifizierung zugänglich.

          

          

            
Application Passwords

            
Für erweiterten Zugriff (Menüs, Einstellungen, Entwürfe) nutzen wir WordPress' eingebauten Application-Password-Flow — seit Version 5.6 (Dez. 2020) im Core enthalten. Kein Plugin nötig.

          

          

            
Datenschutz

            
Alle API-Aufrufe erfolgen direkt aus Ihrem Browser. Ihre Zugangsdaten werden niemals an unsere Server gesendet. Die Extraktion läuft vollständig clientseitig.

          

          

            
Kompatibilität

            
Funktioniert mit ca. 95% aller WordPress-Seiten (Version 5.6+). Einschränkungen bei Cloudflare Bot Protection, bestimmten Security-Plugins oder deaktivierter REST API.
